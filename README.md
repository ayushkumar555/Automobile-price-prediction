# 🚗 Automobile Price Prediction

An end-to-end Machine Learning project to predict automobile prices based on various vehicle specifications and features such as engine size, horsepower, mileage, brand, and body style.

---

## 📌 Project Overview
The objective of this project is to build a predictive model that accurately estimates the market price of a car using historical automotive data. This helps buyers and sellers make informed pricing decisions.

---

## 📊 Features & Dataset Specs
The model uses key vehicle features, including:
* **Engine Characteristics:** Engine size, horsepower, peak RPM, number of cylinders.
* **Fuel & Performance:** Highway MPG, city MPG, fuel type (Gas/Diesel), aspiration.
* **Vehicle Specs:** Wheelbase, curb weight, body style, drive wheels (FWD/RWD/4WD).
* **Target Variable:** `Price` (Continuous Numerical Target).

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn
* **Environment:** Jupyter Notebook / Google Colab

---

## ⚙️ Project Workflow
1. **Data Cleaning:** Handling missing values, out-of-bounds outliers, and invalid data types.
2. **Exploratory Data Analysis (EDA):** Visualizing feature correlations and feature distribution against price.
3. **Feature Engineering & Encoding:** One-Hot Encoding for categorical variables and feature scaling for numerical columns.
4. **Model Training:** Training regression algorithms (e.g., Linear Regression, Decision Tree Regressor, Random Forest Regressor).
5. **Evaluation:** Evaluating models using Metrics like $R^2$ Score, MAE, and RMSE.
